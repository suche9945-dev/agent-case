## 它能做什么

Qoder 是阿里的 AI 编程平台，国内版叫 Qoder CN，入口是 qoder.cn。它提供桌面应用、独立 IDE、CLI、JetBrains 插件、移动 App 和网页入口；你可以用自然语言描述一个开发任务，让它理解当前工作区、创建或修改文件、执行命令，再在预览里看结果。

它适合快速搭一个网页原型、补一个小功能、让 Agent 先写出能运行的骨架，也适合在陌生项目里先问清楚目录和入口。它不适合完全替代代码审查；涉及生产环境、真实用户数据和长期维护的项目，仍然要自己看 diff、跑测试、检查依赖。本文只做一件小事：在一个空文件夹里生成一个单文件计算器。

## 国内怎么用

国内用户直接用 Qoder CN，入口是 qoder.cn。工具档案特别标注：Qoder CN 和国际版 qoder.com 是两套账号与数据，互不相通；国内新手不用先折腾国际版，直接用 CN 版登录即可。本文的下载、登录和实测都在 Qoder CN 完成。

免费档可以登录使用。本文在 Windows 11 桌面端用免费档跑完计算器任务，没有开会员，也没有报错。Qoder 的套餐按每月 Credits 计量，额度用完后会切换到基础模型；具体额度和价格以官方账户页、定价页为准，本文不写死金额。

## 安装

打开 `https://qoder.cn`，下载 Qoder CN 桌面端安装包，双击安装，按向导完成后打开客户端。本文核对时的版本是 **Qoder CN 0.4.8**，系统是 Windows 11，核对日期 2026-10-18。安装过程没有报错。

Qoder 还有 CLI、JetBrains 插件、移动 App 和网页入口，但本文只实测桌面端；没有实际跑过的形态不在这里抄写安装命令。需要 CLI 或插件时，按官方快速开始和对应文档操作，不要把旧教程里的命令直接当成当前版本。

## 登录与开通

打开客户端后，登录页提供手机号验证码登录和账密登录，也可以走「其他方式」。本文用桌面端登录，没有展示任何真实手机号或账号信息。登录成功后进入工作区首页，左侧能看到「新的任务」「搜索工作区」「最近任务」「知识中心」「站点」「自动化」「扩展」等入口。

免费档足够跑本文这个单文件任务。你不需要先买会员，也不需要准备 API Key；先用默认模型把最短链路跑通，再决定要不要订阅。套餐和 Credits 的具体规则以官方账户页为准；如果额度提示出现，先看账户页，不要为了一个练习任务直接买最高档。

## 跑通第一个任务

先在桌面或文档目录新建一个空文件夹，比如 `qoder-test`。在 Qoder 里打开这个文件夹，确认左侧工作区显示的是它，而不是单个文件或上级目录。然后新建任务，把下面这段话粘贴到 Agent 输入框：

```text
在当前文件夹创建一个 index.html，做一个只有两个数字输入框和加减乘除按钮的计算器；只用一个文件，不引入外部依赖。完成后告诉我改了哪些文件，并说明怎么预览。
```

发送前先截一张输入框，确认任务内容完整。发送后 Qoder 会开始分析需求、写文件和执行工具；本次截图里能看到「正在执行中」和「写入文件」的状态。如果它弹出权限确认，确认当前是 `qoder-test` 这个空文件夹后再允许。

![本人实机截图：在 Qoder 里输入单文件计算器任务（来源：本人实机截图）](/guides/qoder/03-输入任务.png)

等任务结束，左侧文件树里应该出现 `index.html`，对话区会告诉你创建了哪些文件以及怎么预览。本次完成提示写的是「已创建 index.html」，并给出直接在文件管理器双击或用浏览器打开的预览方式；内置浏览器里能看到两个数字输入框和加减乘除按钮。

![本人实机截图：Qoder 正在执行任务并写入文件（来源：本人实机截图）](/guides/qoder/04-任务执行.png)

打开 `index.html`，输入两个数字，分别点加、减、乘、除，确认结果会变化。本文实测计算器能正常显示和计算，预览没有报错。看到结果后，先把这张结果图留好；后面写教程、做验收演示都要用它证明你确实在本机跑过。

![本人实机截图：Qoder 生成 index.html 并在内置浏览器预览（来源：本人实机截图）](/guides/qoder/05-运行结果.png)

![本人实机截图：计算器预览，两个输入框和加减乘除按钮（来源：本人实机截图）](/guides/qoder/06-计算器预览.png)

如果预览打不开，先在文件树里确认 `index.html` 存在，再按 Qoder 完成提示里的方式打开；不要在新任务里让它重新生成一遍。计算器这种小任务最适合先跑通，再逐步加样式或历史记录，排错会简单很多。

## 接入自己的模型 / API Key

本文使用的是 Qoder 默认模型，没有接自己的 API Key。官方文档里有模型选择器和 CLI 自定义模型的说明，说明 Qoder 支持切换模型、也提供 CLI 侧的自定义模型配置；但本文没有实际填入 Key 测试，所以不把具体字段和命令写成操作步骤。

如果你要接自己的模型，先看官方的模型选择器文档，确认当前版本支持哪些供应商和接口；再看 CLI 自定义模型文档，确认配置文件和鉴权方式。企业接入、私有化部署和团队额度是另一套文档，需要单独核对。没有实际跑通的路径，本文不写成教程。

## 怎么付费

Qoder 有免费档，登录即可使用；付费套餐按每月 Credits 计量，额度用完后会切换到基础模型。具体价格、Credits 数量、重置规则和国内版/国际版差异，以官方定价页和账户页为准，本文不写死金额。

如果你只是偶尔做小工具，先用免费档跑几次，看看默认模型和额度是否够用；如果每天都要处理大型仓库或使用更高阶模型，再到官方定价页比较档位。不要为了一个计算器任务直接买最高档。

## 常见问题

**Qoder CN 和国际版选哪个？** 国内用户先用 qoder.cn 的 Qoder CN；国际版 qoder.com 是另一套账号与数据，两边不互通。本文的截图和步骤都来自 Qoder CN。

**打开文件夹后 Agent 还是问我在哪个目录？** 大概率是只打开了单个文件，或者打开的是上级目录。回到工作区重新打开 `qoder-test` 这一层，再在任务里说明「当前项目根目录是 qoder-test」。

**预览打不开怎么办？** 先确认文件树里有 `index.html`，再按完成提示里的方式打开；如果内置浏览器没反应，用系统浏览器打开同一个文件。不要直接让 Agent 重新生成，先检查文件是否存在。

**免费额度够不够？** 本文这个单文件计算器在免费档完成，没有开会员。更大的仓库、更多文件或更高阶模型会消耗更多 Credits，具体以账户页和官方定价页为准。

**能不能接自己的模型或 API Key？** 官方文档有模型选择器和 CLI 自定义模型说明，但本文没有实际填 Key 测试。接之前先确认版本、供应商和接口，再按官方文档配置；本文不抄写未验证的命令。

**生成的计算器能直接上线吗？** 先自己检查输入校验、除零处理、移动端布局和浏览器兼容性。本文只验证了两个输入框和四则运算能跑通，没有做完整的异常处理和安全检查。
