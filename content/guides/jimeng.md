## 它能做什么

即梦AI 是字节跳动的图像与视频创作工具，提供网页版和 iPhone App。你可以用中文提示词生成图片或短视频，也可以在智能画布上做局部重绘、扩图和素材组合。工具档案里写它使用字节自家的 Seedream 5.0 Pro 生图和 Seedance 2.5 生视频模型；会员与积分会影响可用的生成通道和模型权益。

它适合做封面、海报草稿、短视频分镜和社交媒体素材，也适合把一句创意快速变成能看的画面。它不适合要求品牌字完全准确、人物手部完全正常、长镜头连续稳定的正式商单；生成结果仍然要你自己检查。本文用它做一件小事：在网页版生成一段 5 秒的社区咖啡店开业短视频。

## 国内怎么用

即梦AI 国内版入口是 jimeng.jianying.com，网页和 iPhone App 都能用。官方档案写注册方式为剪映账号或抖音账号，并需要绑定手机号；登录页会要求阅读并同意用户服务协议、隐私政策和 AI 功能使用须知，工具档案还标注了实名要求。实际流程以你登录时页面弹出的提示为准。

免费档可以登录使用，会员功能需要订阅。本文在网页版用免费额度完成了一次 5 秒视频生成，没有开会员，也没有报错。会员价格、积分和可用通道以官方页面为准，本文不写死金额。境外手机号等没有实测的细节，这里不下结论。

网页版不需要安装。打开 `https://jimeng.jianying.com`，登录后就能进入创作首页；本文的所有步骤都在网页版完成。官方档案还列了 iPhone App，但本文没有在手机上实测，所以不写 App 的具体按钮和安装步骤。

## 登录与开通

点登录后，页面会弹出登录框。可以直接输手机号和验证码，也可以走「其他登录方式」，用剪映账号或抖音账号登录。登录时如果要求绑定手机号或完成实名，按页面提示做；本文的截图只保留输入框，不展示任何真实手机号。

本文用的是免费额度，没有开会员。首页会显示当前的积分或会员入口，具体数字以你账户里看到的为准。一次 5 秒视频会消耗积分；如果提示积分不足，先换更短的视频或更简单的提示词，不要为了一个练习任务直接买会员。

## 跑通第一个任务

进入视频生成页后，先看页面上的参数，不要急着点生成。本文这次选的是 **即梦 Seedance 2.0 mini**，时长 **5s**，比例 **16:9**，清晰度 **720P**。这些参数会直接决定输出，提示词里的“竖版 3:4”不会自动覆盖页面设置。

![本人实机截图：即梦AI 视频生成页，提示词和右侧参数同时可见（来源：本人实机截图）](/guides/jimeng/03-视频生成页.png)

在提示词输入框里填入：

```text
一张社区咖啡店开业海报，暖色灯光，木质吧台，中文标题「今日开业」，竖版 3:4，构图干净，下方留出写地址的位置。
```

点生成后，页面会显示排队或生成中的状态。本文这次显示的是「排队成功进入生成阶段」，等它跑完就能在结果区看到视频。生成过程不需要你一直盯着，但不要连续点多次，避免重复消耗积分。

![本人实机截图：生成任务进入队列，页面提示排队成功（来源：本人实机截图）](/guides/jimeng/04-生成队列.png)

这里有一个实际踩到的坑：提示词写的是“竖版 3:4”，但视频参数选的是 16:9，最后输出按 16:9 走。原因是视频比例由页面参数控制，提示词只能描述内容，不能可靠地改变输出尺寸。要竖版，就在生成前把比例切到 3:4 或 9:16，再点生成；不要只在提示词里写。

![本人实机截图：页面右侧的视频参数，Seedance 2.0 mini、5s、16:9、720P（来源：本人实机截图）](/guides/jimeng/06-视频参数.png)

生成完成后，结果区会出现一段 5 秒视频。本文实际下载到了 MP4，但教程正文需要静态图，所以保留的是视频结果帧的 PNG 截图。你如果要把视频放进自己的作品集，直接下载 MP4；如果只是写教程，截一帧并注明“视频结果截图”即可。

![本人实机截图：生成的 5 秒视频结果帧（来源：本人实机截图）](/guides/jimeng/05-生成结果.png)

看到结果后先检查三件事：画面里有没有出现你要的中文标题，镜头是否稳定，主体有没有明显变形。AI 生成的中文字幕经常会出现笔画错误；这次提示词里的「今日开业」如果显示不完整，最稳的办法是重新生成，或者把文字留到剪辑软件里加，不要反复堆提示词。

## 接入自己的模型 / API Key

本文没有找到即梦AI 网页版面向个人用户的「自定义模型 / API Key」入口。官方页面主要提供平台内的图片、视频、画布和模型选择，工具档案写的是 Seedream 5.0 Pro 和 Seedance 2.5 等自家模型；这次实测也没有出现让用户填 Key 的步骤。

所以这篇不把“怎么填 Key”写成操作步骤。企业接入、开放平台或 API 调用是另一套文档，需要单独核对；如果你只是做内容，直接用网页版的模型和积分就够了。需要自己接模型的场景，可以看站内的 [TRAE 教程](/guides/trae)，那篇有官方文档支持的自定义模型入口。

## 常见问题

**网页版和 App 选哪个？** 只想快速试一次，用网页版；本文的截图和步骤都来自网页版。App 的入口和按钮没有实测，不在本文里编造。

**生成的是图片还是视频？** 先看页面顶部的模式。本文进的是视频生成页，参数里能看到 Seedance、5s、16:9、720P，所以输出是视频；图片生成页的参数和入口不同，不要混着看。

**提示词写了 3:4，为什么输出是 16:9？** 视频比例由页面参数控制，提示词不能可靠地改变画布尺寸。生成前先把比例切到你要的竖版，再点生成；只在提示词里写“竖版 3:4”不够。

**视频里的中文标题不对怎么办？** AI 生成中文文字容易出现笔画错误。先缩短标题、减少画面内文字，再重新生成；如果仍然不稳定，把文字留到剪辑软件里加，画面只保留背景和主体。

**免费额度够不够，要不要开会员？** 本文这条 5 秒视频用免费额度完成，没有开会员。更长、更高清或更高阶的模型可能消耗更多积分，具体以账户页和官方页面为准。

**能不能接自己的模型或 API Key？** 本文没有找到个人版的自定义 Key 入口；官方页面主要提供平台模型和创作工具。企业或开放平台接入需要另看文档，本文没有实测，不写具体步骤。
