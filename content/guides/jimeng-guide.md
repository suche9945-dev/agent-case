> **这篇覆盖什么**：登录 → 认识工作台 → 生成第一张图 → 把图变成视频 → 积分与会员 → 官方 API → 排错。
>
> **你需要准备**：一个手机号（或抖音、剪映账号）、约 20 分钟、能打开网页的浏览器。
>
> **状态说明**：本文依据即梦AI 官网、官方用户协议、付费服务协议与官方工具页整理；会员页与登录弹窗为本人截图，其余为官方辅助图。生成流程尚未在登录状态下实机验证，标注「待实机确认」的按钮位置请以你本机为准。

## 它能做什么

即梦AI 是字节跳动旗下剪映团队的 AI 图像视频工具，运营主体是深圳市脸萌科技有限公司。网页版打开就能用，App 端 iOS 只支持 iPhone，另有安卓版。

能力上分四块：

- **文生图 / 图生图**：输入中文描述出图，也能对现有图片做背景替换、风格保持、局部重绘。
- **文生视频 / 图生视频**：支持首帧 + 尾帧控制；官方 Seedance 2.5 工具页写的是「30 秒原生长镜头、4K、最多 50 个多模态参考素材」。
- **智能画布**：多图融合、一键扩图、图像消除、抠图。
- **工作台辅助**：视频局部重抽、智能编辑、智能超清（最高 8K）、Agent 模式。

适合：做封面图、社媒配图、短视频空镜；需要中文提示词直接出图的人；不想在本地装大模型的人。

不适合：要求像素级可控的商业设计（随机性仍然很大）；需要多镜头连续叙事的项目（单次生成有长度上限）。

## 国内怎么用

网页版地址是 <https://jimeng.jianying.com/>，`data/products/jimeng.yaml` 里 `accessCN` 是 `true`。页面底部有粤ICP备13065114号-22 等备案号，用户协议写明适用中华人民共和国法律——这些是「国内可用」的直接依据。

登录方式有三种，按官方用户协议与付费协议：手机号 + 短信验证码（等于注册/登录剪映账号）、抖音账号授权、剪映账号；iOS 端另有 Apple ID。网页登录弹窗里只显示手机号、抖音、剪映三个入口，**没有微信登录**。

不登录也能用：官方用户协议写明可以「游客模式」使用部分功能，但 AI 内容生成、发布、互动这些要先注册或登录，并完成真实身份信息认证。**注意区分「手机号验证」和「额外身份认证」**：手机号收验证码是登录步骤；协议里的「真实身份信息认证」是另一条要求，登录后是否再弹身份证或人脸，以你实际看到的页面为准，本文没有验证。

手机 App 与网页共用剪映账号，但会员权益是否跨端、是否要满足同一账号绑定条件，官方协议只写了原则性条款；购买前看清楚购买页写的适用端。

## 安装

### 网页版（推荐）

不用安装，Chrome 或 Edge 打开官网即可。生成在云端跑，对本地显卡没要求。

![即梦AI 工作台（未登录）：左侧创作导航、提示词输入框与能力卡片（来源：官方页面 https://jimeng.jianying.com/ai-tool/home）](/guides/jimeng-guide/02-ai-tool-home.png)

### 手机 App

App Store 搜「即梦」下载，标注「仅适用于 iPhone」，免费下载、有 App 内购买；安卓版在应用商店搜同名应用。App 和网页共用剪映账号，作品在同一个账号下。

### 没有桌面客户端

官方协议里提到「客户端应用程序」，但**没有找到 Windows / macOS 桌面端的官方下载页**。想用桌面级功能（画布、局部重绘），用网页版即可，不需要另装软件。

## 登录与开通

1. 打开 <https://jimeng.jianying.com/>，点右上角「登录」。
2. 选手机号收验证码；或点「其他登录方式」，用抖音、剪映授权。
3. 按提示完成真实身份信息认证（生成功能需要）。
4. 进工作台，右上角能看到剩余积分。

![工作台登录弹窗：手机号 + 验证码，下方是抖音、剪映两个第三方入口（未登录状态，来源：本人实机截图，2026-10-21）](/guides/jimeng-guide/05-login.png)

账号是统一的剪映账号：昵称、头像、绑定手机号与剪映共用。官方还写明，注册后连续超过六个月不登录，账号可能被冻结或收回。

## 跑通第一个任务

目标：生成一张图，再把它变成一段视频。以下步骤按官方工具页的说明写，按钮位置以你本机为准（**待实机确认**）。

### 1. 进图片生成

在工作台点「生成」，选「图片」；或者直接打开官方落地页 <https://jimeng.jianying.com/tools/ai-image-generator>，点「立即生成 AI 图片」。

![即梦AI 生图落地页：一屏讲清能做什么，底部是「立即生成 AI 图片」入口（来源：官方页面 https://jimeng.jianying.com/tools/ai-image-generator）](/guides/jimeng-guide/06-image-tool.png)

### 2. 写提示词

第一次别贪多，主体 + 光线 + 风格三样写清就够：

```text
一只橘猫坐在窗台上，午后阳光，浅景深，写实风格，35mm。
```

### 3. 设参数

只改必要的：比例（先用 1:1 或 3:4）、生成数量（一张就够，省积分）。模型版本保持默认，先把链路跑通。

### 4. 生成与验收

点「生成」，等结果。判断标准很直接：主体是不是你要的、构图能不能用、有没有明显的手指或文字崩坏。不满意就改提示词里的风格和光线，比反复点重新生成有效。

### 5. 把图变成视频

在图片结果上找「生成视频」，提示词写「镜头缓慢推近，猫眨眼」，时长按你账号可选的档位选最短的。官方 Seedance 2.5 页写的是「30 秒原生长镜头、4K」，但**第一次不必上长镜头**——先跑通几秒，确认动作不崩再往上加。具体可选时长和分辨率以生成页的下拉项为准（**待实机确认**）。

### 6. 下载

预览满意后下载 MP4。免费档导出的作品带品牌水印，去水印是会员权益之一（官方付费协议列出的会员权益包含「图片、视频去品牌水印」）。

## 接入自己的模型 / API Key

即梦**不开放填第三方模型的 Key**，模型和额度都走官方。但它有官方 API 服务，规则写在付费服务协议里：

- **准入**：API 服务仅面向已开通特定类别会员的用户开放，且要另行购买，仅开通会员不当然获得调用额度。
- **密钥**：Key 由平台分配，不是让你填自己的第三方 Key。
- **计费**：按 Token 消耗计费。
- **入口**：官方公开页没有独立的 API 文档站，实际入口与价格需在会员/控制台页面确认（**待实机确认**）。

所以「接入自己的模型」这件事在即梦这里不成立；能自定义的只有提示词和参数。

## 怎么付费

先免费用。免费额度以积分发放，规则有三点要注意：

- **三类积分**：订阅积分（按会员周期发、当期有效）、赠送积分（**当日有效**）、充值积分（**有效期 2 年**）。
- **每日赠送不是固定权益**：官方写明平台可根据运营策略调整发放对象、数量、频次。
- **免费试用**：Seedance 页的常见问题里说「会提供免费试用积分，具体数量因账号和地区而异」。

要长期用再买会员。个人版四档：**基础、标准、高级、超级**，档位越高每月积分越多；另有团队版。具体金额、年付折扣和当期活动以官方会员页 <https://jimeng.jianying.com/> 为准，**本文不写死价格**——页面的报价形式（年付/月付/限时折扣）经常变。

## 常见问题

> 依据类型：**官方**＝官方协议/页面写过；**建议**＝操作建议，未经实机验证。

**未登录点生成没反应。** 现象是工作台能进，但生成按钮点下去只提示登录。原因是游客模式不能用 AI 生成。怎么办：先登录，再按页面提示完成身份认证。（官方：用户协议 3.3）

**提示积分不足。** 现象是生成到一半中断。原因是赠送积分当日有效，用完当天不补。怎么办：看右上角余额；不着急就等第二天，着急再考虑充值或会员。（官方：付费协议 4.2.2）

**生成的图和描述差很远。** 现象是主体对了、风格不对。原因是风格词太笼统。怎么办：把「好看」换成具体词，例如「胶片颗粒、暖色逆光、35mm」。（建议）

**人物手部崩坏。** 现象是手指数量不对。原因是模型对细粒度结构稳定性有限。怎么办：让人物离镜头远一点、少露手；或用首尾帧、参考图约束画面。（建议）

**首尾帧之间会跳。** 现象是两帧接起来不连贯。怎么办：首尾帧用同一角色、同一场景、同一光照，提示词里写清过渡过程，例如「先弯腰、再屈膝、最后落座，约 3 秒」。（建议，来自社区教程）
