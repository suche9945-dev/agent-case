## 它能做什么

WorkBuddy 是腾讯的办公智能体，提供桌面端和移动 App。它可以用自然语言安排多步骤任务，读取本地文件、分析数据、编写代码、调用技能，最后交付文档、表格、PPT 等成果。桌面端和移动 App 使用同一账号，手机可以远程续聊和查看电脑上的任务。

它适合把会议记录、表格、资料整理成能直接用的办公产物，也适合处理一批本地文件的重复劳动。它不适合完全放开不管的任务，尤其是涉及真实客户数据、合同金额和对外承诺的内容；工具界面也会提示「内容由 AI 生成，请核实重要信息」。本文用它做一件具体的小事：读取本地会议记录，整理成一张带优先级的待办表。

## 国内怎么用

WorkBuddy 国内版入口是 workbuddy.cn，桌面端和移动 App 都能用。登录页支持手机验证码、微信、企业微信、邮箱和 SSO 等方式；工具档案写注册使用腾讯统一身份账号，手机号、邮箱或用户名都可以。本文用桌面端登录，没有展示任何真实手机号或账号信息。

免费体验版可以登录使用，更多额度需要开通付费会员。本文在 Windows 11 桌面端用免费体验版跑完会议记录整理任务，没有开会员，也没有报错。积分、会员档位和价格以官方定价页和账户页为准，本文不写死金额。境外手机号等没有实测的细节，这里不下结论。

## 安装

打开 `https://www.workbuddy.cn`，从官网下载 Windows 桌面端安装包，双击安装，按向导完成，再打开客户端登录。本文核对时的版本是 **WorkBuddy 5.8.3**，系统是 Windows 11，核对日期 2026-10-18。安装和登录过程都没有报错。

WorkBuddy 还有移动 App，可以在同账号下远程查看和续聊电脑任务；本文只实测桌面端，没有在手机上跑完整任务，所以不写移动端的具体按钮。需要移动端时，按官方多设备文档操作。

## 登录与开通

打开桌面端后，用手机验证码、微信、企业微信、邮箱或 SSO 登录。登录成功后进入工作区，左侧有「新建任务」「助理 BETA」「专家」「技能」「连接器」「定时任务」「资料库」等入口。本文只用到最基础的新建任务和本地文件读取，不需要先配置连接器或定时任务。

免费体验版足够跑本文这个任务。你不需要先买会员，也不需要准备 API Key；如果首页出现积分包或会员提示，先看账户页里的剩余额度，再决定要不要购买。本文没有开通会员，任务正常完成。

## 跑通第一个任务

先准备一个专门测试的空文件夹，比如 `workbuddy-test`，在里面新建 `meeting-notes.txt`，内容如下：

```text
周三产品例会
1. 首页改版：小林负责，周五前给出第一版
2. 上线公告：阿杰负责，下周一发布
3. 用户反馈：小周负责，本周内整理 20 条重点问题
4. 数据看板：小林和阿杰一起，下周三前确认指标
```

在 WorkBuddy 里打开这个文件夹，新建任务，把下面这段话粘贴到输入框：

```text
读取当前文件夹的 meeting-notes.txt，把每条整理成待办表，输出 xlsx；列包括：事项、负责人、截止时间、优先级。不要添加原文没有的负责人和日期。
```

发送后 WorkBuddy 会先读取文件，再生成表格。如果它要本地文件或写文件的权限，确认当前是 `workbuddy-test` 这个测试文件夹后再允许。任务执行时页面会显示「思考中」或处理状态；本文这次大约两秒进入处理，完整任务用了不到两分钟。

![本人实机截图：在 WorkBuddy 里输入读取本地会议记录并输出 xlsx 的任务（来源：本人实机截图）](/guides/workbuddy/03-输入任务.png)

![本人实机截图：WorkBuddy 正在处理本地文件和生成待办表（来源：本人实机截图）](/guides/workbuddy/04-任务执行.png)

任务完成后，它会告诉你生成了 `周三产品例会待办表.xlsx`，并说明文件和源文件在同一个目录。打开表格能看到 4 条待办，列是事项、负责人、截止时间、优先级；负责人分别是小林、阿杰、小周、小林和阿杰，截止时间保留原文的「周五前 / 下周一 / 本周内 / 下周三前」。

![本人实机截图：WorkBuddy 生成的周三产品例会待办表，共 4 条待办（来源：本人实机截图）](/guides/workbuddy/05-结果表格.png)

这里有一个值得保留的处理：原文没有写优先级，WorkBuddy 没有自己编高/中/低，而是把这一列统一写成「未标注」，并在单元格里做了下拉选项，方便你之后手动补。它也没有把相对日期换算成具体日期，因为原文只写了「周三产品例会」，没有给会议日期，强行换算等于替原文编日期。

![本人实机截图：WorkBuddy 对优先级和相对日期的处理说明（来源：本人实机截图）](/guides/workbuddy/06-优先级说明.png)

拿到表格后先核对四件事：4 条事项是否都在，负责人是否与原文一致，截止时间有没有被改写，优先级是不是你想要的表达。确认后再把 xlsx 发给同事；如果想让 AI 按截止时间推断优先级，可以继续在对话里说明规则，让它重填一版。

WorkBuddy 有免费体验版，登录即可使用；更多额度需要开通付费会员。本文的会议记录整理任务在免费体验版完成，没有开会员。具体积分、会员档位、价格和额度重置规则，以官方定价页和账户页为准，本文不写死金额。

## 常见问题

**WorkBuddy 读不到我的本地文件怎么办？** 先确认文件真的在当前打开的文件夹里，文件名和任务里写的一致；再检查是否给了本地文件读取权限。本文把 `meeting-notes.txt` 和输出表格放在同一个 `workbuddy-test` 文件夹，读取和写入都没有问题。

**优先级为什么都是「未标注」？** 原文没有写优先级，WorkBuddy 没有自行编造高/中/低，而是保留「未标注」并做了下拉选项。这是保守处理，不是失败；你可以手动补，也可以给它一条明确的推断规则让它重填。

**截止时间为什么不换成具体日期？** 原文只有「周五前」「下周一」这类相对表述，没有会议日期。直接换算需要假设会议是哪一天，容易编造；本文保留原文的相对时间，交给使用者确认。

**生成的 xlsx 在哪里？** 完成提示会说明文件和源文件在同一个目录。本文的输出是 `周三产品例会待办表.xlsx`，和 `meeting-notes.txt` 放在 `workbuddy-test` 里；找不到时先在文件夹里按修改时间排序。

**免费体验版够不够？** 本文这个 4 条待办的任务在免费体验版完成，没有开会员。更大的文件、更多步骤或高级技能可能消耗更多额度，具体以账户页和官方定价页为准。

**能不能接自己的模型或 API Key？** 官方模型文档提到可以在本地配置第三方模型的地址与密钥，但本文没有实际填写测试。接之前先确认版本和接口，再按官方文档配置；本文不抄写未验证的步骤。
