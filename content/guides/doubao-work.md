## 它能做什么

豆包工作是字节跳动的智能体平台，提供桌面客户端，也在豆包和飞书里设置了工作入口。它围绕一个工作目标自动规划步骤、搜索资料、调用技能和连接器，最后交付文档、表格、PPT、网页或应用。对国内用户来说，它更像一个能直接交付办公产物的助手，而不是只会在聊天框里回答问题的机器人。

它适合有明确产出的任务：把一段需求变成计划表、把资料整理成文档、把数据做成表格、把会议内容整理成待办。它不适合完全放开不管的任务，尤其是涉及真实客户数据、合同金额、合规判断和对外发布的内容；这些仍然要你自己核对。本文用它做一件具体的小事：根据一句需求，生成一份社区咖啡店的 7 天开业准备计划表。

## 国内怎么用

豆包工作在国内可以直接使用，官网是 doubao.com/work。它有两种入口：网页版打开就能用，桌面端需要下载安装。官方页面写到的注册方式包括手机号、邮箱、运营商一键登录、Apple ID 和抖音账号；本文实测用桌面端登录，没有要求先订阅会员。

免费档可以登录使用，会员功能需要另外订阅。本文这个表格任务在免费档完成，没有开会员，也没有遇到额度拦截。具体会员档位、额度和价格以官方定价页和你账户里的套餐页为准，本文不写死价格。境外手机号、实名认证等细节不在本文的实测范围内，没有验证过的部分不在这里下结论。

## 安装

如果你只想快速试一下，先打开 `https://www.doubao.com/work`，登录后直接进工作台，不需要安装。网页版适合临时做一份表、整理一段资料；如果你要处理本地文件、使用桌面端连接器，或者希望任务在电脑上持续运行，再装桌面端。

桌面端从官网的下载入口获取安装包，下载后双击安装，按向导完成，再打开客户端登录。本文使用的是 Windows 11 上的豆包桌面端 **2.32.6**，核对日期 2026-10-18。安装过程没有报错，登录后直接进入「今天有什么工作要处理？」的工作台首页。

## 登录与开通

打开桌面端后，用手机号、邮箱、运营商一键、Apple ID 或抖音账号登录即可。登录成功后先看首页左侧的「新工作」「定时任务」「技能」「连接器」「云盘」等入口；本文只用到最基础的任务输入，不需要先配置技能或连接器。

免费档足够跑本文这个任务。你不需要先买会员，也不需要准备 API Key；如果首页出现会员或额度提示，先看账户页里的剩余额度，再决定要不要订阅。本文没有开通会员，任务正常完成，说明这个表格场景不依赖付费档。

## 跑通第一个任务

在桌面端首页的任务输入框里，新建一个工作，把下面这段话粘贴进去：

```text
帮我做一份「社区咖啡店 7 天开业准备计划」，输出为表格，列包括：日期、当天重点、具体事项、负责人、完成标准。按第 1 天到第 7 天排，默认只有店长和 2 名店员，不写具体预算金额。
```

发送后，豆包工作会先拆解任务，再调用表格能力。它如果反问你要不要补充信息，可以直接回「按你的假设直接做，输出表格」。等任务跑完，完成提示会告诉你表格已经交付，并给出打开或下载的入口。

![本人实机截图：在豆包工作里输入 7 天开业计划任务（来源：本人实机截图）](/guides/doubao-work/03-输入任务.png)

本次生成的是 **5 列 × 7 行** 的表格：列是日期、当天重点、具体事项、负责人、完成标准，行是第 1 天到第 7 天。完成提示里还写明负责人只使用「店长 / 店员 A / 店员 B / 全员」这几种口径，全文没有写具体预算金额，表内没有公式和金额计算。这些都可以在结果页里核对。

![本人实机截图：任务完成提示和表格结构说明（来源：本人实机截图）](/guides/doubao-work/04-结果概览.png)

打开结果后，先看表头和 7 行日期是否齐全，再看每一天的事项有没有落到具体动作。比如第 1 天是场地交接与设备清点，第 2 天是设备安装调试与吧台动线，第 3 天是原料进货与耗材盘点，第 4 天是出品标准化，第 5 天是深度清洁与氛围布置，第 6 天是试营业彩排，第 7 天是查漏补缺与定岗定责。发现某天事项太粗，可以继续在对话里让它拆细。

![本人实机截图：生成的 7 天计划表上半部分（来源：本人实机截图）](/guides/doubao-work/05-计划表上半.png)

![本人实机截图：生成的 7 天计划表下半部分（来源：本人实机截图）](/guides/doubao-work/06-计划表下半.png)

结果页提供打开和下载入口。能直接在在线表格里编辑，就直接改；需要留档，就点下载保存到本地。本文没有把表格导出成另一种格式，保留的是结果页截图和在线表格；如果你要把这份表交给别人，建议下载后再检查一遍列宽、换行和负责人分工。

## 接入自己的模型 / API Key

本文没有找到豆包工作桌面端面向个人用户的「自定义模型 / API Key」入口。官方页面强调的是平台模型、技能和连接器，工具档案里写的是按任务调度字节自家的 Doubao-Seed 2.1 Pro 等模型；这次实测也没有出现让用户填 Key 的步骤。

所以这篇不把「怎么填 Key」写成操作步骤，避免把没有验证过的入口编出来。如果你需要接自己的模型，优先看支持自定义模型的工具，例如站内的 [TRAE 教程](/guides/trae)；企业接入、开放平台或连接器授权是另一套文档，需要单独核对。没有实际跑通的路径，本文不写成教程。

## 怎么付费

豆包工作有免费档，登录即可使用；会员功能需要订阅。本文的表格任务在免费档完成，没有开会员。具体价格、额度、每档包含的权益和是否自动续费，以官方定价页和站内套餐页为准，本文不写死金额，也不把活动赠送达当成长期免费档。

如果你只是偶尔做表格、整理文档，先用免费档跑一两次，看看额度和导出限制是否够用；如果每天都要处理大量文件或使用高级连接器，再到官方定价页比较档位。不要为了一个小任务直接买最高档。

## 常见问题

**网页版和桌面端选哪个？** 只是临时生成一份表，先用网页版；要处理本地文件、使用桌面端连接器或让任务在电脑上持续运行，再用桌面端。本文的截图来自桌面端，网页版入口相同。

**表格在哪里打开或下载？** 任务完成后，结果页会给出打开和下载入口。如果交付的是飞书表格，打开时可能需要登录对应的飞书账号；下载后再用表格软件打开。找不到入口时，先回到完成提示那一屏，不要在新对话里重新生成。

**免费档够不够？** 本文这个 7 天计划表在免费档完成，没有开会员。更复杂的任务、更多文件或高级技能可能消耗更多额度，具体以账户页和官方定价页为准。

**能不能接自己的模型或 API Key？** 本文没有找到个人版的自定义 Key 入口；官方页面主要讲平台模型、技能和连接器。企业接入需要看单独的开放平台或企业文档，本文没有实测，不写具体步骤。

**生成的计划表能直接发给客户吗？** 先检查三件事：负责人是不是你实际有的人员，完成标准是不是可验收，日期和开业节点有没有冲突。AI 会按假设补全细节，涉及预算、合同、资质和对外承诺的内容要自己确认。
