> **这篇覆盖什么**：注册登录 → 认识界面 → 文生视频 / 图生视频各跑一遍 → 会员与灵感值 → 开放平台 API → 排错。
>
> **你需要准备**：一个手机号（或快手账号）、约 20 分钟、能打开网页的浏览器。
>
> **状态说明**：本文依据可灵AI 官方用户协议、付费协议、使用指南与开放平台页面整理，配图为官方公开页面截图。首次生成流程尚未在登录状态下实机验证，标注「待实机确认」的按钮位置请以你本机为准。

## 它能做什么

可灵AI 是快手的视频与图像生成工具。官方使用指南把能力分成两块：基础功能是文生视频、图生视频、多图参考；进阶功能是首尾帧、数字角色 2.0、动作控制、对口型、运镜控制。

形态上，除了网页，还有 iOS / Android App、macOS（M 芯片与 Intel）和 Windows 桌面端、快手小程序，以及给开发者用的 CLI / MCP 与开放平台 API。

![官方使用指南目录：文生视频、图生视频、多图参考，以及首尾帧、动作控制、对口型等进阶功能（来源：官方文档 https://docs.qingque.cn/d/home/eZQBGvsEtlGCz5-IhhQP3S-eM?identityId=2CYV3VL6EGS）](/guides/kling-guide/03-help.png)

适合：短视频空镜、产品展示动画、把一张插画变成动态壁纸；需要中文提示词直接出片的人。

不适合：要精确到逐字对口型的成片；需要长镜头连续叙事的项目——单次时长有上限，长片要自己分段拼接。

![可灵AI 国内站首页：顶部提示全球站已迁至 kling.ai，主视觉是 Kling 4.0（来源：官方页面 https://klingai.com/cn/）](/guides/kling-guide/01-home.png)

## 国内怎么用

国内站是 <https://klingai.com/cn/>，`data/products/kling.yaml` 里 `accessCN` 是 `true`。界面是简体中文、人民币计价，用户协议里的经营主体是北京快手科技有限公司，争议适用中国法律——这些都是「国内可用」的直接依据。

**国际站已经换域名了**：klingai.com 现在是中国站，全球站迁到了 <https://kling.ai/>，国内站首页顶部有一条常驻横幅写着这件事。老教程里「国际版是 klingai.com」的说法已经过时。

登录方式有两种，官方用户协议写得很清楚：用手机号收动态验证码注册；或者用快手账号授权登录。手机号如果之前没注册过快手，验证时会顺带注册一个快手账号。

免费额度是有的，但**官方页面没有给出具体数值**：会员页只写「登录即可获得限时免费灵感值」，没登录看不到个人额度。所以本文不写「送多少灵感值」，你登录后在个人空间看实际数字。

## 安装

### 网页版（最省事）

不用安装，浏览器打开 <https://klingai.com/cn/>，登录后进创作界面。生成在云端跑，对本地显卡没要求。

![可灵AI 网页创作界面（未登录，推广弹窗已关闭）：提示词框、「视频生成」、Kling 4.0、全能参考与「720p · 10s · 16:9」参数、生成按钮（来源：官方页面 https://app.klingai.com/）](/guides/kling-guide/05-app.png)

### 手机 App

官网首页有 iOS 与 Android 的扫码下载入口。App 和网页共用同一个账号，适合随手看进度、下载成片。

### 桌面端

官网下载区提供 macOS（M 芯片 / Intel 芯片）与 Windows 客户端，Windows 安装包文件名形如 `KlingAI-setup-1.3.2.exe`。桌面端适合长时间挂着跑任务。

### 开发者形态

开放平台在 <https://klingai.com/dev>，另有 CLI / MCP 入口，官方首页把它作为「让 Agent 调度可灵」的卖点。具体安装命令以开放平台文档为准，本文不转抄未核对的命令。

## 登录与开通

1. 打开 <https://klingai.com/cn/>，右上角点「登录」。
2. 选手机号验证码，或快手账号授权。
3. 勾选协议，进入创作界面。

登录后先确认两件事：

- **灵感值余额**：在个人空间看当前剩余，免费额度是登录后发放的限时灵感值。
- **当前会员状态**：会员与免费档的差别主要在去水印、1080p 生成、快速通道、运镜与视频延长、画质增强、并发数这些权益上。

官方付费协议写明：购买付费服务必须先登录，游客模式不能下单支付。所以想升级会员，先登录再操作。

## 跑通第一个任务

目标：先用文字生成一段短视频，再用一张图生成一段。以下按钮文案按官方使用指南与网页界面写，具体位置以你本机为准（**待实机确认**）。

### 1. 进视频生成

登录后进入创作界面，左侧导航选「视频生成」，生成类型选「文生视频」。

### 2. 写提示词

提示词写得越具体，运动越可控。示例：

```text
黄昏的海边，一个穿白衬衫的人背对镜头慢慢走，海风吹动衣角，镜头缓慢跟随，电影感，35mm。
```

### 3. 设参数

先看三个参数：时长、分辨率、模型。**网页界面和 API 是两套口径，不要混用**：

- 网页端（本文截图可见）：未登录界面底部显示「视频生成 / Kling 4.0 / 全能参考 / 720p · 10s · 16:9」，登录后可选哪些档位以你看到的为准（**待实机确认**）。
- API 文档（Kling 3.0 Turbo）：时长 3–15 秒任选，默认 5 秒；分辨率 720p / 1080p。这是接口参数，不能直接当作网页下拉项的说明。
- Kling 4.0 单次最长 30 秒：来自国际站功能页与开放平台卡片，网页端是否已开放 30 秒，需要你登录后确认。

第一次跑建议选最短时长、720p，失败成本最低。

### 4. 生成与验收

点「生成」，等任务跑完，在结果里预览。判断标准很简单：人物走路时脚有没有打滑、背景有没有突然变形。这两项稳，说明这条链路对你是可用的。

### 5. 图生视频

回到「视频生成」，切到「图生视频」，上传一张主体清晰的图（人物或风景都行），提示词写「镜头缓慢环绕，人物轻微转头」，再生成一次。

这一步的意义是验证「图片 + 文字」这条链路。很多人第一次失败是因为运动描述太弱——只写「动起来」，模型往往只让画面轻微抖动。把动作和运镜写具体，成功率会明显提高。

## 接入自己的模型 / API Key

网页版**可以选平台内置模型**（截图上能看到 Kling 4.0 下拉），但不能填第三方模型的 Key；要接自己的程序，走可灵开放平台。

- 入口：<https://klingai.com/dev>，右上角有「API 控制台」。
- 鉴权：请求头 `Authorization: Bearer <API_KEY>`。
- 国内基址：`api-beijing.klingai.com`（API 文档示例）。海外基址 `api-singapore.klingai.com` 本轮没有在直接读到的 API 页面中再次确认，**待核实**。
- 能力：文生视频、图生视频、多图参考、视频延长、数字人、对口型、视频特效等，按官方 API 文档调用。
- 状态：开放平台首页把 Kling 4.0 API 标为「即将开放」，目前正式上线的是 Kling 3.0 Turbo 等档位；这个状态可能变化，以控制台为准。

## 怎么付费

先用免费额度：登录后能领限时免费灵感值，但**官方没有公布具体数值**。够不够跑完上面两段取决于你的账号与当时活动，**不保证一定够**；如果不够，页面会提示，按提示决定等第二天、充值还是买会员。

会员分六档：黄金、铂金、钻石、黑金、团队版、企业会员，档位越高每月灵感值越多。具体金额和当期折扣以官方会员页 <https://klingai.com/app/membership/membership-plan> 为准，**本文不写死价格**。

灵感值的有效期要分清：充值购买的灵感值有效期 2 年；会员权益按月发放的那部分，**自发放之日起 1 个月内有效**。这和「月底清零」不是一回事，不要把两个口径混着说。

## 常见问题

> 依据类型：**官方**＝官方协议/页面写过；**建议**＝操作建议，未经实机验证。

**提示词被判定不合规。** 现象是提交后直接失败。原因是提示词里有真人姓名、品牌标识或敏感场景。怎么办：改成描述性写法，去掉具体人名和商标。（建议）

**人物手指和脸崩。** 现象是几秒里手指数不对、脸部变形。原因是模型对细粒度结构稳定性有限，人物在画面中占比越大越明显。怎么办：把人放远、少露手；或改用图生视频，用一张干净原图约束画面。（建议）

**图生视频几乎不动。** 现象是结果和原图差不多。原因是运动描述太弱。怎么办：把动作和运镜写具体，例如「镜头向左平移，头发被风吹动，人物转身看向镜头」。（建议）

**免费额度看不到数字。** 现象是会员页只写「登录可领」，不知道还剩多少。原因是免费灵感值是登录后按活动发放的。怎么办：登录进个人空间查看余额；官方没有公开固定数值，别信「每天送多少」的说法。（官方：付费协议写免费服务以页面展示为准）

**导出带水印。** 现象是画面角落有平台标识。按官方会员权益，去品牌水印是会员权益之一。怎么办：确认当前会员状态；不升级就只能接受水印或裁剪。（官方：付费协议会员权益条款）
