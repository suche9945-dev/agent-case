## 它能做什么

TRAE 是字节跳动的 AI 开发工具，国内版官网是 trae.cn。它把 Agent 任务工作台和 IDE 放在同一个客户端里：你可以用自然语言描述一个任务，让它读取当前项目、创建文件、修改代码、执行命令，再在预览里看结果。它适合快速做一个网页原型、补一个小功能、让 AI 先搭出可运行的骨架，也适合在陌生项目里先问清楚目录和入口。

它不适合完全替代你的判断。涉及生产环境、真实用户数据、复杂权限和长期维护的项目，仍然要自己看 diff、跑测试、检查依赖。本文只做一件小事：在一个空文件夹里生成一个 `index.html`，确认 TRAE 能完成“理解任务、写文件、给出预览方式”这条最短链路。

## 国内怎么用

国内用户优先用 trae.cn 的 TRAE 国内版。官方下载页在 2026-10-18 列出 Windows 10/11、macOS 12.0 及以上，以及 Debian/Ubuntu 的 `.deb` 和 Fedora/RHEL 的 `.rpm` 包；本文实测环境是 Windows 11。国际版 trae.ai 是另一套入口，仓库里的工具档案标注它存在网络限制，国内新手不必先折腾国际版。

登录入口在客户端里，官方快速开始文档写到的登录方式包括手机号、抖音账号、Apple 账号和 Google 账号等，实际以你安装后看到的界面为准。免费档可以登录使用；官方下载页在 2026-10-18 写新用户登录送 4500 积分，还有每日签到、每月 500 积分和大学生额外 2000 积分的活动。积分是否到账、活动是否仍有效，要以你登录后的账户页为准，本文不把活动数字当成永久承诺。

本文这个任务不需要先付费，也不需要自己准备 API Key。你用默认模型就能跑完；如果之后要接自己的模型，再看后面的「接入自己的模型 / API Key」。

## 安装

打开 `https://www.trae.cn/download`，在 TRAE 卡片里选择 Windows (x64)，下载安装包。下载页同时给出了 macOS 和 Linux 的入口，macOS 用户注意系统要在 12.0 及以上。本文只走桌面版，CLI、VS Code 插件和 JetBrains 插件没有实测，所以不在这里抄写未验证的安装命令；需要这些形态时，按官方文档对应页面操作。

![TRAE 官方下载页，页面列出 Windows 10/11、macOS 和 Linux 入口（来源：官方页面 https://www.trae.cn/download）](/guides/trae/01-下载页.png)

下载完成后双击安装包，按向导下一步即可。第一次启动时，TRAE 会让你选择主题和语言，也可以从 VS Code 或 Cursor 导入已有配置，或添加 TRAE 的命令行入口。官方快速开始文档把这一步概括为“安装 TRAE 并完成初始设置”，具体选项以你安装时的界面为准。

![TRAE 官方快速开始文档，包含支持的系统、安装、登录和打开项目步骤（来源：官方文档 https://docs.trae.cn/ide_get-started-with-trae）](/guides/trae/02-快速开始文档.png)

本文核对时的版本是 **TRAE 3.4.3**，系统是 Windows 11，核对日期 2026-10-18。你安装到的版本可能更新，按钮位置和文案可能略有差异，遇到不一致时以你本机界面为准。

## 登录与开通

安装完成后打开 TRAE，在登录页选择你有的账号登录。登录成功后，先看一眼账户或套餐页里的积分余额和当前套餐，确认自己用的是免费档还是已经订阅。官方下载页写的 4500 积分是活动口径，实际到账情况以账户页为准；如果你只是跟着本文跑一个小页面，默认模型和免费额度通常够用，不必先买套餐。

登录后不需要先建 API Key。TRAE 自带模型列表，默认模型可以直接在对话输入框右下角选择；本文实测用的是默认模型，没有接自己的 Key。等你确认默认模型能跑通，再决定要不要接自定义模型，排错会简单很多。

## 跑通第一个任务

先在桌面或文档目录里新建一个空文件夹，名字可以叫 `trae-test`。打开 TRAE，在左侧面板点击「打开文件夹」，或者从左上角的「项目 > 打开文件夹」进入，选中这个空文件夹。这里要选文件夹，不要只打开一个单独的文件，否则 Agent 不容易判断当前工作目录。

打开后确认左侧出现了这个文件夹的名字。默认进入的是 IDE 窗口；如果你在 Agent 窗口里，也可以从右上角切换。官方文档把两个窗口的分工写得很清楚：Agent 窗口适合用任务的方式让 AI 协作，IDE 窗口适合直接读代码、改文件、运行和调试。本文用 Agent 方式完成第一个任务。

在 Agent 输入框里粘贴下面这段话，然后点发送：

```text
在当前文件夹创建一个 index.html，页面居中显示「Hello TRAE」和当前时间；只用一个文件，不引入外部依赖。完成后告诉我改了哪些文件，并说明怎么预览。
```

发送前可以截一张输入框，方便之后核对任务内容。发送后 TRAE 会开始拆解任务、创建文件；如果它弹出文件修改或命令执行的权限提示，确认当前是 `trae-test` 这个空文件夹后再允许。等任务结束，左侧文件树里应该出现 `index.html`。

![本人实机截图：TRAE 的任务描述与预览局部（来源：本人实机截图）](/guides/trae/03-任务与预览.png)

![本人实机截图：Agent 输入框中的任务和 TRAE 的完成提示（来源：本人实机截图）](/guides/trae/04-输入任务.png)

接下来看结果。最直接的方式是双击 `index.html`，或者在文件树里右键选择用浏览器打开；也可以按 TRAE 在完成提示里给出的本地服务方式预览。本文实测直接打开文件就能看到居中的「Hello TRAE」和当前时间，页面没有引入外部依赖。

![本人实机截图：浏览器预览显示 Hello TRAE 和当前时间，左侧文件树中是 index.html（来源：本人实机截图）](/guides/trae/05-运行结果.png)

看到页面后，先做两个检查：文件树里确实有 `index.html`，预览里的文字和时间确实在刷新。两项都对，第一个任务就算跑通。此时不需要继续加功能，先把这张结果图留好；后面写教程、做验收演示都要用它证明你确实在本机跑过。

## 接入自己的模型 / API Key

本文实测使用的是 TRAE 默认模型，没有接自己的 API Key。下面这段是官方文档给出的入口和字段，方便你确认“能不能接、接哪种格式”，不代表本文已经实际接通。

在 IDE 或 Agent 窗口里进入「设置 > 模型」，点击「添加模型」。你可以选 TRAE 预设的模型服务商，也可以选「自定义模型」。预设服务商会让你选择计费或资源使用方式、模型和 API 密钥；自定义模型则需要填 API 格式、请求地址、模型 ID、展示名称和鉴权信息。

API 格式有两种：**OpenAI Chat Completions** 兼容 OpenAI 的 `/v1/chat/completions` 规范，适合大多数 OpenAI 兼容服务；**Anthropic Messages** 兼容 Anthropic 的 `/v1/messages` 规范，适合 Claude 系列或兼容 Anthropic Messages 的服务。请求地址可以填完整 URL，也可以填基础地址让 TRAE 按所选格式拼接路径。高级配置里还能设置模型系列、上下文窗口、工具调用轮数、是否支持图片输入、思考模式和采样参数；不确定时先留默认。

![TRAE 官方文档的「添加模型」窗口，列出预设服务商和自定义模型入口（来源：官方文档 https://docs.trae.cn/ide_models）](/guides/trae/06-模型设置.png)

如果你要接 DeepSeek、Kimi、GLM 等国内服务，优先看服务商自己的 API 文档，确认请求地址、模型 ID 和计费方式，再填到 TRAE 里。不要把 API Key 写进教程正文或截图；添加后如果连接失败，TRAE 会显示服务商返回的错误信息，先从 Key、地址和模型 ID 三项排查。

## 怎么付费

本文不写死价格。TRAE 国内版有不同套餐档位，内置模型调用会消耗积分或套餐额度；具体价格、额度和重置规则以官方计费页和站内套餐页为准。你可以先在免费档里跑完本文的小任务，确认工作流适合自己，再决定要不要订阅。如果你只是偶尔生成小页面，先看账户页的剩余积分，不必为了一个练习任务直接买最高档。

## 常见问题

**登录后没有看到 4500 积分？** 官方下载页把它写成新用户活动，实际到账可能受账号、地区、活动时间和是否首次注册影响。先看账户页的积分记录；如果确实没有，按官方页面上的活动规则或客服入口核对，不要按“一定有”来规划用量。

**打开文件夹后，Agent 还是问我在哪个目录？** 大概率是只打开了单个文件，或者打开的是上级目录。回到「项目 > 打开文件夹」，选中 `trae-test` 这一层，再在 Agent 里说明“当前项目根目录是 trae-test”。

**预览打不开，或者地址是 `file://`？** 先确认 `index.html` 真的在文件树里。双击文件，或右键选择浏览器打开；如果浏览器拦截本地文件，再按 TRAE 完成提示里的本地服务方式预览。本文实测双击文件即可看到结果。

**模型列表里没有我想要的模型？** 内置模型会随版本和套餐变化。先在输入框右下角的模型列表里找，找不到再到「设置 > 模型 > 添加模型」里接预设服务商或自定义模型；具体支持范围以官方模型文档为准。

**国内版和国际版怎么选？** 国内用户先用 trae.cn 的国内版；国际版 trae.ai 是另一套入口，仓库里的工具档案标注它存在网络限制。本文的下载、登录和实测都在国内版完成。
