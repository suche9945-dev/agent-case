# 教程源文件模板

复制到 `content/guides/<slug>.md` 后填写。`slug` 用小写字母和连字符，文件名就是页面地址。

```markdown
---
title: 工具名上手教程：从安装到跑通第一个任务
tool: cursor
summary: 写给第一次用这个工具的国内用户：怎么装、怎么登录、怎么跑通第一个任务，以及卡住时先查哪里。
updatedAt: 2026-10-20
screenshots:
  - /guides/<slug>/01-下载页.png
  - /guides/<slug>/02-登录.png
sourceUrls:
  - https://example.com/official-docs
  - https://example.com/download
  - https://example.com/pricing
---

## 它能做什么

用 2–3 句写清适用场景，也写清不适用场景。

## 国内怎么用

官方支持地区、账号类型、实名、境外手机号、支付方式。只写官方有出处的；
代理、虚拟卡、代充等接法可以写，但要标明是实际做法，不要写成官方支持。

## 安装

桌面版、命令行、IDE 插件分别怎么装。命令只能抄官方文档，并标注核对时的版本和日期。

## 登录与开通

从哪里登录，要不要先订阅，免费档能用到什么程度。

## 跑通第一个任务

3–5 步，每一步写清「点哪里 / 输入什么 / 看到什么」。

## 接入自己的模型 / API Key

能不能填自己的 Key，兼容哪些接口，以官方文档为准。

## 怎么付费

不写死价格，指向站内套餐页或写「价格见本站套餐页」。

## 常见问题

3–5 条，每条写「现象 → 原因 → 怎么办」，并给出来源。

## 延伸阅读

官方文档 2–4 条；第三方教程 2–3 篇，只放你实际打开读过正文的。
```

## 配图要求

- 每篇至少 6 张图，其中至少 2 张你自己实机截的。
- 图片放在 `public/guides/<slug>/`，用 `/guides/<slug>/01-下载页.png` 这种路径。
- 每张图的 alt 或图注写来源：本人实机截图 / 官方页面 URL / 第三方教程 URL。
- 图里不能出现账号名、邮箱、API Key、真实姓名、本机用户名。
- 宽度控制在 1600px 内，单张 500KB 内。
- 不要用 AI 生成假界面，也不要拿宣传图冒充自己看到的界面。
