# 验收清单

交之前从头过一遍，每一条都要能**当场演示**。看不明白的在群里问，不要猜。

## A. 能不能跑

- [ ] A1 `pnpm install` 全新环境无报错
- [ ] A2 `pnpm dev` 起得来，`/guides` 返回 200
- [ ] A3 `pnpm build` 通过
- [ ] A4 `pnpm typecheck` 通过
- [ ] A5 浏览器控制台没有报错和水合警告

## B. 页面

- [ ] B1 `/guides` 是三栏：左目录 / 正文 / 右目录
- [ ] B2 左目录列出全部 22 个工具，按「编程工具 / 图像与视频 / 办公 Agent」三组
- [ ] B3 有教程的 5 个可点；其余置灰并标「教程整理中」，点不动
- [ ] B4 当前所在文章的目录项有高亮
- [ ] B5 三个分组可折叠展开，按钮有 `aria-expanded`
- [ ] B6 总览页有「怎么看这份指南」和 5 张教程入口卡片（标题、摘要、工具名、更新时间、阅读时长）
- [ ] B7 右目录点一下能跳到对应小节
- [ ] B8 `/guides/<slug>` 顶部有分类、标题、摘要、更新时间
- [ ] B9 工具信息条有 logo、名字、官网链接、国内是否可用、免费档
- [ ] B10 正文的标题、列表、表格、代码块、图片都渲染正常
- [ ] B11 滚动时右目录高亮当前小节
- [ ] B12 上一篇 / 下一篇能点，顺序和 `data/guides.json` 一致
- [ ] B13 访问不存在的 slug 返回 404 页面，不是空白
- [ ] B14 每篇教程的浏览器标签标题是自己的文章名
- [ ] B15 1440 / 768 / 390 三个宽度下没有横向滚动条、没有元素重叠
- [ ] B16 手机宽度下左目录收起来了，并且能打开、能选到文章
- [ ] B17 只用键盘（Tab / Enter）能走完目录、卡片、上一篇下一篇，焦点看得见
- [ ] B18 页面是浅色（paper 皮肤），和 `design-demo/` 里工具页、套餐页的浅色一致，不是深色

## C. 导入

- [ ] C1 `pnpm import:guides` 能跑通，输出一行汇总
- [ ] C2 `data/guides.json` 每条都符合 `src/lib/guides.ts` 的 `Guide` 类型
- [ ] C3 frontmatter 缺字段 → 报错、退出码 1、`data/guides.json` 没有被改动
- [ ] C4 `tool` 写成不存在的 slug → 报错
- [ ] C5 `updatedAt` 写成 `2026/10/20` 或 `2026-10-20T00:00:00` → 报错
- [ ] C6 `screenshots` 里放一个不存在的文件 → 报错
- [ ] C7 连跑两次，`data/guides.json` 完全一致（可以 `certutil -hashfile` 比）
- [ ] C8 把 `data/guides.json` 清空成 `[]`，页面变成「暂无教程」而不是报错——证明页面没有把正文硬编码进组件

## D. 内容

- [ ] D1 5 篇，对应 5 个不同工具
- [ ] D2 至少覆盖 2 个分类
- [ ] D3 每篇正文 1500–3000 字（不含代码块和表格）
- [ ] D4 每篇的小节按任务书 5.2 来，缺的小节在 `DELIVERY.md` 说明了原因
- [ ] D5 每篇至少 6 张图，其中至少 2 张是自己实机截的（看得出你的系统、时间、界面版本）
- [ ] D6 每张图都标了来源（本人截图 / 官方页面 URL / 第三方教程链接），没有 AI 生成的假界面
- [ ] D7 图里没有账号名、邮箱、API Key、真实姓名、本机用户名（官方的和别人的图也算）
- [ ] D8 每篇 `sourceUrls` 至少 3 条，且都能打开
- [ ] D9 没有「强大的」「一站式」「赋能」「轻松上手」「无论你是……还是……」这类话
- [ ] D10 安装命令抽查 2 条，和官方文档逐字一致
- [ ] D11 每篇写的「国内能不能用」和 `data/products/<slug>.yaml` 的 `accessCN` 不矛盾

## E. 工程与交付

- [ ] E1 代码里没有 `any`（`grep -rn ": any" src/` 应该没有）
- [ ] E2 组件和样式里没有写死的颜色值（`grep -rn "#[0-9a-fA-F]\{3,6\}" src/` 只在 tokens.css 里出现）
- [ ] E3 页面样式都是 `*.module.css`，没有一堆内联 `style={{}}`
- [ ] E4 没有新增依赖；如果加了，`DELIVERY.md` 写了理由
- [ ] E5 提交是分阶段的（骨架、页面、导入、每篇教程），不是一个大 commit
- [ ] E6 `DELIVERY.md` 五件事都写了：怎么跑、为什么选这 5 个、每篇的核对来源和日期、已知问题、依赖说明
