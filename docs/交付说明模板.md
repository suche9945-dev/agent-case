# 交付说明模板

复制到根目录 `DELIVERY.md` 后填写。五节都要有，尤其是「已知问题」要如实写。

## 1. 怎么跑

```bash
pnpm install
pnpm import:guides
pnpm dev
```

访问 `http://localhost:3000/guides`。构建与类型检查：

```bash
pnpm build
pnpm typecheck
```
