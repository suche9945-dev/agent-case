## 先选一条认证路线再截图

R6 复核指出：桌面账号、Web/API Key、自定义模型是三条不同路线，不能只拍一种却写成「必须先拿 Key」。

| 路线 | 需要拍什么 | 说明 |
|---|---|---|
| A 桌面端 + DeepSeek 账号 | 登录后的界面、模型列表里可选模型 | 官方账号插件文档支持这条路；按钮位置以你本机版本为准 |
| B Web UI + API Key | 设置 → 模型，保存后的状态（Key 打码） | 官方 Web UI 指南的路径 |
| C 自定义提供商 | 自定义模型 API 表单填好后的状态（Key 打码） | 不需要 DeepSeek 账号 |

三选一拍就行，**不必三种都拍**；但正文和截图要对应同一条路线。
